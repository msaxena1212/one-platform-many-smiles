# Procurement Phase 3

This package exposes the Procurement lifecycle through the Finance Console at `/finance/procurement`.

## Added
- Procurement Control Tower route and navigation.
- Lifecycle counts for PR, RFX, vendor quotes, PO, shipments, GRN, landed cost, payable invoices and purchases.
- Refresh action backed by the Phase 2 Procurement data access layer.
- Finance console title and navigation entry.

The package retains the Phase 1 database migration and Phase 2 domain services.
